# Folia 日文歌・繁中即時翻譯

讓 Folia 顯示日文原詞與繁體中文翻譯，中文跟著歌曲時間逐字亮起。
這是獨立的 Folium 社群模組，並非 Folia 或 Google 官方產品。

## 功能

- 優先使用歌詞資料中的中文譯文，透過 OpenCC 轉為臺灣繁體字形，日文原詞不轉換。
- 歌詞含日文假名時，缺少中文的句子由 Google 免費網頁介面翻譯成繁中，英文混合句也使用自動語言判斷。
- 先處理目前唱到的句子，再處理後續歌詞；短句批次翻譯，分行對不上時退回逐句翻譯，避免字幕串位。
- 原文使用原有逐字時間軸；中文按原句起迄時間平均分配亮起進度。中文時間是**估算動畫，非語意逐字對齊**。
- 使用 Folia 的歌詞時鐘，跟隨暫停、跳轉及歌詞偏移；支援 Folia 取得歌詞的 Now Playing 模式。
- 翻譯快取最多 40 首且限制容量，副歌重複文字只翻一次。切歌後忽略舊請求結果。
- 請求串行、至少間隔 1.2 秒。遇 403／429 停止並冷卻，保留已取得的字幕；不無限重試。

## 安裝

需要 Folia `>=0.7.27 <0.8.0`，使用 Folium 1.8 的公開介面。

1. 從本儲存庫 Releases 下載 `jp-zh-live-lyrics-1.0.0.zip`。
2. 在 Folia「設定 → 模組」開啟模組系統，匯入 ZIP，並閱讀及確認模組啟用提示。
3. 首次啟用會切到「日文・繁中同步」歌詞樣式。之後也可透過模組命令「開啟日文・繁中同步字幕」切回。
4. 播放帶時間軸歌詞的日文歌。第一次翻譯可能需要等待，已快取內容可直接顯示。

手動安裝也可把 ZIP 裡的 `jp-zh-live-lyrics` 資料夾放到 Windows 的
`%APPDATA%\Folia\mods\`，再在模組頁重新掃描。**不要覆蓋 Folia 的 `app.asar`。**
本模組未經 Folium 官方簽章，Folia 會顯示「未驗證」，不代表官方認證。

## 設定與命令

展開模組可以調整自動翻譯、中文逐字亮起、下一句與字幕大小。
提供「重試目前歌曲的繁中翻譯」、「查看日文翻譯狀態」與「清除本模組的翻譯快取」。
關閉 Google 自動翻譯後仍可顯示現成中文字幕與既有快取；關閉後不再排新請求，已送出的請求無法撤回。
清除快取會移除本模組存的翻譯；自動翻譯開啟時會重新翻目前歌曲。

## 資料與限制

自動翻譯預設開啟；啟用模組前請確認接受下列行為：

- 缺少中文時，只把歌詞文字傳送至 `translate.googleapis.com`。不傳送音訊、帳號憑證或本機檔案。
- 使用的是 Google 未承諾穩定性的免費網頁介面，**不是 Google Cloud Translation 正式 API**。可能限流、失效或變更格式；此模組不規避限制。
- 翻譯保存在 Folia 本機的本模組資料區，不上傳到 GitHub。
- 沒有原詞或時間軸時不會聽音辨識。只有羅馬字、全漢字而沒有假名的歌曲不會自動判定成日文。
- 首次翻譯不是零延遲，不能保證翻譯品質或全曲中文逐字語意對齊。來源只有逐行時間時，原文逐字也只能估算。
- 本版本沒有預先取得外部音樂播放器「下一首」的能力，也不改動原始歌詞、音訊或歌單。
- 模組畫面在即時播放器生效；OBS／匯出等非主視窗不啟動翻譯請求。

權限：`net.fetch`（Google 翻譯）、`filesystem.data`（翻譯快取）、`visualizer.mode`（切換到雙語歌詞畫面）。

## 開發與驗證

Node.js 24.15 以上：

```sh
npm ci --ignore-scripts
npm run build
npm test
```

`dist/jp-zh-live-lyrics/` 是可安裝目錄。測試使用自行撰寫的短句與模擬回應，不包含第三方歌曲歌詞或使用者快取。
實際連線與本機驗證結果記錄在 [驗證紀錄.md](驗證紀錄.md)。
